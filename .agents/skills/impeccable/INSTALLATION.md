# Impeccable project skill

Upstream commit: ece38d9904b8a619b3f77cab476eacad09c4fb11

This directory contains the upstream Codex skill and its support files.
The project hook uses .agents/skills instead of the upstream .codex/skills path.

Open a new Codex chat in this repository after checkout.
Use $impeccable to select the skill.
Approve the project hook in /hooks if Codex prompts for trust.
The launcher downloads its pinned engine on first use. This needs network access.

See https://impeccable.style for usage and update instructions.
